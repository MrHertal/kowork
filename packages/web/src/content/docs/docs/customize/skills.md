---
title: Skills
description: Add reusable skills that give Kowork specialized instructions for a task.
---

A **skill** is a set of reusable instructions for a particular kind of work. Skills can help Kowork follow a specialized process or create a specific kind of result.

## Add a popular skill

1. Select **Settings** in the sidebar.
2. Select **Skills**.
3. Find a skill under **Popular**.
4. Select **Add**.

The skill moves to **Added** and is available to Kowork. You can also open the attachment menu beside the task message box and select **Skills**.

:::tip
The **skill-creator** skill can help you create a new skill or improve an existing one by asking questions and writing the reusable instructions for you.
:::

## See added skills

Open **Settings** > **Skills**. Each skill under **Added** shows its name and description.

When Kowork loads a skill during a task, the task steps show a **Skill** item with the skill's name.

## Remove a skill

1. Open **Settings** and select **Skills**.
2. Find the skill under **Added**.
3. Select **Remove** beside it.

For skills added from a local folder, one folder can contain several skills. Removing one of those skills may remove every skill loaded from that folder. Kowork asks for confirmation and shows how many skills are affected. The files in the folder are not deleted.

## Add a custom skill

:::note
Custom skills are intended for people who already have a skill folder or a hosted skill index. For most needs, start with a popular skill.
:::

1. Open **Settings** and select **Skills**.
2. Find **Custom skill** under **Popular** and select **Add**.
3. Choose a source:
   - **Local folder**: Choose a folder containing one or more `SKILL.md` files.
   - **Remote URL**: Enter the `http://` or `https://` URL of a hosted skill index.
4. Select **Submit**.

Only add skills from sources you trust. Skills provide instructions that can influence how Kowork handles a task.
