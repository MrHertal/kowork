---
title: Create Your First Task
description: Choose a folder, describe the result you want, and review Kowork's work.
---

A task is a conversation with Kowork about one outcome. For your first task, use a folder containing only the files you want Kowork to work with.

## 1. Start a new task

Open Kowork and select **New** in the left sidebar. The new-task screen includes a message box, a folder selector, the approval mode, and the current AI model.

## 2. Choose a folder

1. Select **Folder** below the message box.
2. Select **Choose folder**.
3. Choose the folder that contains your source files or where you want the finished files saved.

The folder's name replaces **Folder** when it is selected. Kowork can read and change files in this folder while completing the task.

:::caution
Kowork works directly with the files in the selected folder. For important files, keep a backup and review the changes it makes.
:::

## 3. Describe the outcome

In the message box, explain what you want in everyday language. Include the source files to use, the result to create, and any requirements that matter.

For example:

> Read `sales.xlsx` and create a one-page PDF summary with total revenue, the three best-selling products, and a monthly revenue chart. Save it as `sales-summary.pdf`.

You can also use the attachment button to add photos or files to your message.

:::tip
Describe the finished result rather than every action Kowork should take. Add file names, format, audience, and any details that must be included.
:::

## 4. Review the task settings

- Check the model shown at the bottom of the message box. Select it if you want to use another model from a connected provider.
- Keep **Manual** selected for your first task. Kowork will pause before sensitive actions so you can approve or deny them.

## 5. Send and review

1. Select the send button to begin. Kowork creates the task and starts working.
2. Answer any questions Kowork asks.
3. When a permission request appears, read the requested action and choose whether to allow or deny it.
4. Follow the task's progress and read the final response.
5. Open the finished files and check that they match your request. Send another message in the same task if you want changes.

You can select **New** at any time to start another task. Existing tasks remain available under **Recents** in the left sidebar.
