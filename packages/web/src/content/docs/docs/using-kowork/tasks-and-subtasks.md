---
title: Tasks and Subtasks
description: Organize work, follow progress, and understand delegated subtasks.
---

A **task** is your conversation with Kowork and the work connected to it. It keeps the messages, selected folder, model, permissions, and results together.

## Start a task

1. Start a new task from the sidebar.
2. Select the folder Kowork should work in.
3. Choose **Manual** or **Auto** for sensitive actions.
4. Enter a clear outcome, useful context, and any limits.
5. Attach specific files if needed, then send the message.

Kowork creates the task when you send the first message. You can continue the same task with corrections, follow-up questions, or more work that belongs with the same context.

See [Folders and Files](/docs/using-kowork/folders-and-files/) and [Permissions and Safety](/docs/using-kowork/permissions/) before starting work on sensitive files.

## Write an effective request

Include:

- **Outcome:** what should be created, changed, or explained.
- **Inputs:** the filenames or attached documents to use.
- **Constraints:** what must not change, the intended audience, or a deadline.
- **Output:** the format and filename you want.

For example:

> Review the three interview notes in this folder. Group the findings into five themes and create `research-summary.docx` for a non-technical audience. Do not change the original notes.

## How subtasks work

For larger work, Kowork can launch **subtasks** to handle focused parts in parallel or separately. A subtask belongs to the main task and uses the same folder.

When a subtask appears in the activity:

1. Select it to open its details and progress.
2. Use **Main task** in the header to return.
3. Continue giving instructions in the main task.

You cannot send messages directly from a subtask. Kowork brings the result back into the main task when the delegated work finishes.

:::note
Permission requests from a subtask can appear in the main task. If the main task uses Auto, its subtasks also automatically approve permission requests.
:::

## Keep work manageable

- Continue an existing task when the new request depends on its earlier messages or files.
- Start a new task for a different folder or unrelated outcome.
- Ask Kowork to divide a broad request into subtasks when independent parts can be handled separately.
- Review delivered files and important conclusions before using them outside Kowork.

:::caution
Subtasks can read files, run commands, and create or change files as part of the main task. They follow the main task's permission mode, so review the scope before enabling Auto.
:::
