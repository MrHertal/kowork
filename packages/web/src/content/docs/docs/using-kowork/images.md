---
title: Create and Edit Images
description: Create, inspect, convert, and revise raster image files.
---

Kowork includes built-in image capabilities for common raster formats. You can ask it to create an image from scratch or work with an existing image in your selected folder.

## What Kowork can do

Kowork can help you:

- create banners, thumbnails, social cards, diagrams, and other raster images;
- inspect an image's format, dimensions, transparency, and metadata;
- convert between formats, compress files, or remove metadata;
- resize, crop, rotate, or flip an image;
- adjust brightness, color, sharpness, blur, or grayscale;
- add captions, watermarks, or logos;
- combine images into a collage, grid, or side-by-side comparison;
- create an animated GIF or extract its frames.

Files in the selected folder can use PNG, JPEG, WebP, GIF, BMP, TIFF, ICO, or AVIF. PNG, JPEG, WebP, and GIF images can also be attached directly to a message. SVG files are not raster images and are not covered by these built-in image capabilities.

## Create an image

1. Start a task and select the folder where the result should be saved.
2. Describe the image's purpose, dimensions, content, and visual style.
3. Give the output filename and format.
4. Review the delivered image and open it in your usual image viewer or editor.

For example:

> Create `event-banner.png` at 1600 × 900 pixels. Use a dark blue background, a large “Community Night” heading, and space in the lower-right corner for a sponsor logo.

## Work with an existing image

Put the image in the selected folder and identify it by name, or attach a supported image with **Add photos or files**.

1. State what should change and what must remain unchanged.
2. Include exact dimensions, file-size limits, or output format when they matter.
3. Ask for a new output filename unless you intentionally want to replace the original.
4. Inspect the result for composition, readability, colors, and cropping.

For example:

> Crop `team-photo.jpg` to a centered square, resize it to 800 × 800 pixels, and save the result as `team-photo-square.webp`. Do not change the colors.

:::caution
Keep an original copy of important images. Converting formats, reducing file size, removing metadata, or resizing can permanently discard information.
:::
