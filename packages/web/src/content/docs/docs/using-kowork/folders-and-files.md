---
title: Folders and Files
description: Choose where Kowork works and give it the files it needs.
---

Every task works in a folder. This gives Kowork a clear place to find source files and save its work.

## Choose a folder

Before sending the first message in a new task:

1. Select **Folder** below the message box.
2. Choose a recent folder or select **Choose a different folder**.
3. Confirm that the folder name shown below the message box is the one you intend to use.
4. Describe what you want Kowork to do.

If you do not attach a folder, Kowork uses its default folder. Select **Detach folder** to return to that default before starting the task.

:::note
The folder is set when you send the first message. To work in a different folder, start a new task and select that folder first.
:::

## What folder access means

Kowork can inspect files in the selected folder and, when needed, create or change files there. Choose the narrowest folder that contains everything required for the task rather than a broad folder such as your entire home folder.

In the desktop app, the task information panel shows the folder used by the task. You can also open it in your computer's file manager.

Kowork may ask for permission before reading, changing, or searching files, running a command, or accessing something outside the selected folder. See [Permissions and Safety](/docs/using-kowork/permissions/).

:::caution
Folder selection is context, not a complete security boundary. If you approve access outside the folder, or use Auto mode, Kowork may act on other locations requested during the task.
:::

## Attach a file to a message

Use an attachment when Kowork needs a specific file but does not need the rest of its folder.

1. Select the **+** button in the message box.
2. Select **Add photos or files**.
3. Choose one or more supported files.
4. Add instructions such as “Summarize this report” or “Compare these two images,” then send the message.

You can also drag files onto Kowork. Supported attachments include images, PDFs, text files, Word (`.docx`), Excel (`.xlsx`), and PowerPoint (`.pptx`) files.

An attachment does not change the task's folder. For work that creates or edits several files, place them in one folder and select that folder when starting the task.

:::tip
Name the exact input and desired output in your request. For example: “Read `survey.csv` and save a chart and summary in this folder.”
:::

For document-specific workflows, see [Create Office Documents](/docs/using-kowork/office-documents/).
