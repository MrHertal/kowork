# Active work notes

For a substantial task that may span sessions or agents, write a short Markdown note in `docs/work/active/`. Skip this for small changes. The note is working state, not permanent documentation.

Include only facts another agent needs to continue:

```md
# Task title

## Objective and acceptance criteria

## Relevant files and constraints

## Current state and next action

## Decisions and attempts

## Verification
```

Update the note when the next action or verification status changes. When the task is finished, delete it or move a concise record of a lasting decision to the appropriate documentation. Do not preserve reasoning transcripts, secrets, or raw logs here.
